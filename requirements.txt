# LEE ESTO ANTES DE INSTALAR
# ############################################################################
#
# NO instales torch desde este archivo. `pip install torch` baja la build de
# CPU y todo corre 5-10x mas lento sin avisarte de nada -- fue exactamente lo
# que le paso a este proyecto. torch va aparte, con el indice de CUDA:
#
#   pip install torch==2.13.0+cu126 torchvision==0.28.0+cu126 \
#       --index-url https://download.pytorch.org/whl/cu126
#
# Despues:
#
#   pip install -r requirements.txt -c constraints.txt
#
# `constraints.txt` fija la version EXACTA de los paquetes con los que se
# probo el sistema (y con los que corre la integracion continua). Aqui solo
# van rangos con tope: una version mayor nueva (OpenCV 5, SQLAlchemy 2.1,
# numpy 3...) no se instala sola hasta que alguien la pruebe. Asi fue como
# SQLModel 0.0.45 rompio la busqueda por fechas en instalaciones nuevas.
#
# Verifica siempre despues de instalar:
#
#   python -c "import torch; print(torch.cuda.is_available())"   # debe decir True
#
# cu126 sirve para GPUs NVIDIA de arquitectura Turing en adelante (RTX 20xx,
# 30xx, 40xx). La de este proyecto es una RTX 4050 Laptop (sm_89).
# ############################################################################

# --- Rostros -----------------------------------------------------------------
# InsightFace en vez de face_recognition/dlib: no necesita CMake ni Visual
# Studio Build Tools en Windows, y da embeddings de 512-d mucho mas precisos.
# LICENCIA: los pesos buffalo_l son de uso NO comercial. Ver docs/licencias.md.
insightface>=1.0.1,<3

# LA VERSION ESTA FIJADA A PROPOSITO, NO LA SUBAS SIN LEER ESTO:
# onnxruntime-gpu 1.23 en adelante esta compilado contra CUDA 13 y pide
# cudart64_13.dll / cublasLt64_13.dll, que PyTorch cu126 no incluye. Cuando no
# las encuentra NO lanza ningun error: cae a CPU en silencio y el
# reconocimiento facial pasa de 12 ms a 77 ms por frame sin que nada lo avise.
# 1.22.0 es la ultima build contra CUDA 12, que es la que corresponde a
# torch cu126.
onnxruntime-gpu==1.22.0

# Al instalar insightface, pip arrastra `onnxruntime` (CPU) como dependencia y
# ese paquete ECLIPSA a onnxruntime-gpu: comparten el mismo directorio. Si
# `ort.get_available_providers()` no lista CUDAExecutionProvider, corre:
#     pip uninstall -y onnxruntime
#     pip install --force-reinstall --no-deps onnxruntime-gpu==1.22.0
# (el --force-reinstall es necesario porque desinstalar uno rompe al otro)
